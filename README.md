1-й спринт. Mesto v12.2.25

В проекте я поработала с приложением Mesto. Это интерактивная веб-страница, куда можно добавлять фотографии. Также фотографии можно оценивать лайком и/или удалять.

Моя работа над проектом будет состоять из двух частей:
1. Провести регрессионное тестирование по готовым тест-кейсам.
2. Перепроверить баги, то есть провести ретест.
Для выполнения заданий я буду использовать тестовый стенд приложения, а результаты фиксировать в Google Документах и Таблицах.

Часть 1: регрессионное тестирование

Задачи

 - Познакомиться с сервисом Mesto.
 - Протестировать сервис по тест-кейсам и проставить статусы выполнения проверок.
 - Составить баг-репорты.

Часть 2: ретест багов

Задачи

 - Изучить список багов, которые нашли другие тестировщики в сервисе Mesto.
 - Убедиться, что разработчики исправили баги: провести ретест, используя тестовый стенд.
